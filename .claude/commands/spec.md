Structure: Goal (1 sentence) · Non-goals · Constraints · Acceptance criteria (checkable list) · Loop plan (table: loop / owner / DoD / verification) · Open questions.
If Open questions is non-empty, immediately switch to the `grilling` skill to resolve them. A spec with open questions is not buildable.
